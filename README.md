# GraduationTesting
Actuarial Graduation testing in R 

This project performs actuarial graduation tests on mortality data, including:

- Chi-square test
- Signs test
- Cumulative deviation test


## Files
- `scripts/graduation_tests.R` – main R script
- `results/cumulative_deviation_plot.png` – plot of cumulative deviations


## How to Run
1. Open `graduation_tests.R` in RStudio.
2. Run all sections sequentially.
3. Outputs (plots and statistics) will be saved in the `results/` folder.
